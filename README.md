# Solpredict - Aqueous Solubility Prediction Environment

An OpenReward environment where agents train ML models to predict aqueous solubility (LogS) from molecular SMILES notation.

## Task Description

Agents receive training data and must:
1. Train a solubility prediction model
2. Generate predictions for test molecules
3. Submit predictions for scoring

**Scoring**: RMSE on the hidden test set. Reward = -RMSE (higher is better, max is 0).

## Data

| Split | Source | Compounds | Description |
|-------|--------|-----------|-------------|
| Train | AqSolDB (minus ESOL) | 7,093 | Scaffold-split training set |
| Validation | AqSolDB (minus ESOL) | 1,772 | Scaffold-split validation set |
| Test | ESOL (Delaney) | 1,128 | External test set (hidden LogS) |

**Why this split?**
- AqSolDB is a large, curated solubility dataset (~10K compounds)
- ESOL (Delaney) is a classic benchmark commonly understood by reviewers
- Removing ESOL overlap from AqSolDB ensures strict external validation
- Scaffold splitting ensures train/val contain structurally different molecules

## Agent Interface

### Available Data Files (mounted at /data/)
- `/data/train.csv`: Training data with columns [SMILES, LogS]
- `/data/val.csv`: Validation data with columns [SMILES, LogS]
- `/data/test_smiles.csv`: Test molecules with column [SMILES] (predict LogS)

### Available Tools
- Full CLI access: `bash`, `read`, `write`, `edit`, `glob`, `grep`, `ls`
- Can install packages: `pip install rdkit scikit-learn xgboost pytorch`
- Submission: `submit(submission_path="/path/to/submission.csv")`

### Submission Format
```csv
SMILES,LogS
CCO,-0.77
c1ccccc1,-2.18
```

## Expected Performance

| Model Type | Expected RMSE | Reward |
|------------|---------------|--------|
| Mean predictor | ~2.5-3.0 | -2.5 to -3.0 |
| Linear + ECFP | ~1.0-1.3 | -1.0 to -1.3 |
| Random Forest + ECFP | ~0.8-1.0 | -0.8 to -1.0 |
| GNN/Transformer | ~0.6-0.8 | -0.6 to -0.8 |
| State-of-art | ~0.5-0.7 | -0.5 to -0.7 |

## Setup

### 1. Prepare Data (one-time)
```bash
pip install rdkit tdc pandas requests
python prepare_data.py
```

This creates:
- `data/train.csv` - Training data (7,093 compounds)
- `data/val.csv` - Validation data (1,772 compounds)
- `data/test_smiles.csv` - Test SMILES only (1,128 compounds)
- `data/test_ground_truth.json` - Hidden test labels (for scoring)

### 2. Upload Data to GCS
Upload the `data/` contents to your GCS bucket under `solpredict/`.

### 3. Run Locally
```bash
pip install -r requirements.txt
python server.py
```

### 4. Test with Agent
```bash
export OPENAI_API_KEY="sk-..."
python test_agent.py
```

### 5. Docker Build
```bash
docker build -t solpredict:test .
```
